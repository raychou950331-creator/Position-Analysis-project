## 期末專題：美股內部交易監測系統 (MVP)

### 專案啟動方式
1. 建立虛擬環境：`python -m venv venv`
2. 啟動虛擬環境：`.\venv\Scripts\activate`
3. 安裝必要套件：`pip install -r requirements.txt`

### 執行 Flask 專案
1. 確保 `.env` 檔案已設定正確的資料庫連線字串。
2. 執行指令：`python app.py`
3. 開啟瀏覽器進入：`http://127.0.0.1:5000`
